# 標註規則（codebook）

驗收標準 P0 第 4 條要求標註規則必須文件化。這份是給 LLM 弱標註的 prompt 依據，
也是人工校驗 gold set 時的判準。**兩者必須用同一份，否則一致率沒有意義。**

修訂日期：2026-09-10
狀態：初版，尚未用真實留言校準過。第一批 50 則 spike 跑完要回來修。

---

## 一、情感三分類

標的是**留言者對該則貼文主題的態度**，不是留言的整體語氣。
「這個判罰很扯」是負面（對判罰不滿），不是中立（雖然它在陳述事實）。

| 標籤 | 判準 | 例 |
|---|---|---|
| `positive` | 表達讚賞、認同、興奮、支持 | 「這個超車神了」「策略下得漂亮」 |
| `negative` | 表達不滿、失望、憤怒、質疑 | 「這個判罰很扯」「車隊又搞砸了」 |
| `neutral` | 純陳述、純提問、無明顯傾向 | 「所以他總共進站幾次？」「明天幾點開始」 |

### 中立類別的處理（這是 macro-F1 的殺手）

正負兩類好分，**中立難分**，這是中文情感分析的已知難題。
macro-F1 0.75 很可能是「正負各 0.85、中立 0.55」的平均，
所以驗收方式是**每一類都要報 P／R／F1**，中立類不設硬門檻，
但報告必須討論它為什麼低。以下是造成中立類難分的四種情況，標註時依此判：

1. **反諷**：「真是好棒棒」字面正面實際負面 → 標 `negative`
2. **混合**：「車手表現很好但車隊策略爛」→ 依**主要對象**判，
   若貼文主題是車隊則標 `negative`
3. **純資訊提問**：「幾點開始」→ `neutral`
4. **情緒但無對象**：「啊啊啊啊」→ `neutral`，因為判不出針對什麼

### 排除

- **非中文留言直接過濾，不標註。** 不做翻譯後標註，因為翻譯會改變語氣強度。
- 純表情符號、純標籤（hashtag）、純 tag 他人的留言不標註。

## 二、主題五分類

一則留言只給一個主題。同時涉及多個時，依**留言者主要在談什麼**判。

| 標籤 | 涵蓋 | 邊界說明 |
|---|---|---|
| `driver_performance` | 車手的駕駛表現、超車、失誤、心態 | 談車手個人能力歸這類 |
| `team_strategy` | 進站時機、輪胎選擇、車隊指令、隊內順序 | 談決策歸這類，談車輛快慢歸 `race_event` |
| `penalty_dispute` | 判罰、賽會裁決、規則爭議 | 只要在談「這樣判對不對」就歸這類 |
| `race_event` | 事故、安全車、天氣、機械故障、賽道狀況 | 談發生了什麼事歸這類 |
| `other` | 週邊、轉播、粉專本身、閒聊 | 判不出來就歸這類，不要硬塞 |

**`penalty_dispute` 與 `team_strategy` 最容易混淆。** 判準：
爭論的對象是**賽會**就是 `penalty_dispute`，是**車隊**就是 `team_strategy`。

## 三、去識別化（先於標註執行）

隱私紅線：**任何含他人留言的原始資料，永遠不進公開 repo。**
`deidentify.py` 在標註之前先跑，處理五類：

| 類型 | 置換為 | 說明 |
|---|---|---|
| 連結 | `[連結]` | 含縮網址與裸網域 |
| @提及 | `[提及]` | 半形 `@` 與全形 `＠` 都處理 |
| 信箱 | `[信箱]` | 順序上必須排在連結規則之前，否則會被當網域吃掉 |
| 電話與長數字 | `[號碼]` | 台灣手機、市話、8 碼以上連續數字 |
| 正文人名 | `[人名]` | 百家姓 + 1 到 2 字的啟發式 |

**公眾人物必須保留**，否則分析就沒有對象可分析。
車手與車隊名走 `data/public_figures.json` 白名單。
那份清單是起始集，譯名沒有標準答案，需要人工複核與補齊。

偏誤方向是刻意的：**寧可過度遮蔽也不要漏遮。**
每次遮蔽都記進 audit log，可事後複核有沒有誤刪車手名。
`NOT_NAMES` 是精確度的代價（例如「馬上」「高速」以姓氏字開頭但不是人名），
這份清單不完整就會誤遮，所以 audit log 必須留著。

## 四、gold set 與一致性

- 從全量 LLM 標註中**抽驗 300 則**建立 gold set
- 抽樣要分層，不要全抽同一場比賽，否則主題分布會偏
- **同一批 50 則要獨立標註兩次**，記錄兩次的一致率
- 一致率低於 0.8 的類別，回來修這份 codebook 再重標，
  不要直接調整模型去遷就不穩定的標籤
